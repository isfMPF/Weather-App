Описание

Веб-приложение для отображения текущей погоды, используя данные из внешнего API. Приложение получает прогноз погоды и выводит основную информацию на экран.

Технологии

Frontend: HTML, CSS, Thymeleaf

Backend: Java, Spring Boot.

API: WeatherAPI.com
